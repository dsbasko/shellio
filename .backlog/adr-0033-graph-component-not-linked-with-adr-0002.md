# ADR-0033 добавляет компонент в набор ADR-0002 без строки связи

ADR-0033, «Компонент графа»: «Это новый элемент набора компонентов ADR-0002».
В ADR-0002 набор перечислен поимённо и назван ограниченным («Набор компонентов ограничен и не становится универсальным фреймворком»).
Строки «Дополняет» нет в шапке ADR-0033, строки «Дополнено» нет в шапке ADR-0002.

Нужно записать дополнение с обеих сторон.
