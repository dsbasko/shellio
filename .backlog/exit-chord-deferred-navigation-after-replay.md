# Отложенный `mode.navigation` первого аккорда может прийти после повтора второго

Первый `Ctrl-\` меняет режим в решении маршрутизатора, а ввод с поля снимает отложенно, через `defer(run_key)` (`window_ui.rs`, ветка `Decision::Run` в `on_key_down`).
Второй `Ctrl-\` обрабатывается синхронно в мониторе: `Replay` ставит ввод и повторяет пару.
Если оба нажатия уже стоят в очереди событий, порядок может стать таким: повтор, затем отложенный `on_mode_key(Navigation)`, который безусловно ставит `Navigation` и снимает ввод с поля.
Пара доставлена, но панель осталась в `Navigation`, вопреки ADR-0010 «Уточнено в P0.3».
Найдено чтением кода и порядка очереди AppKit, не воспроизводилось.

Нужно в `on_mode_key` для `ModeAction::Navigation` брать режим из `router.mode(&receiver)`, как уже сделано для `Toggle`.
