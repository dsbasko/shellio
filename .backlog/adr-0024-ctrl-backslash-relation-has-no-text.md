# Связь ADR-0024 с ADR-0010 про `Ctrl-\` не подкреплена текстом записи

Шапка ADR-0024: «Дополняет ADR-0010: `Ctrl-\` переключает режимы в обе стороны».
В тексте ADR-0024 такого решения нет: `Ctrl-\` встречается только в этой строке шапки.

Нужно либо записать решение в «Решении» ADR-0024, либо убрать строку связи с обеих сторон.
