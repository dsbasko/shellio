# Отвергнутые варианты в пяти записях повторяют прежнее состояние

Вариант совпадает с состоянием из «Контекста», а причина пересказывает само решение:

- ADR-0025: «Разделы воркспейсов в навигаторе. Не разделяют пространство глобально.»
- ADR-0028: «Вкладка на каждого агента. Владелец хочет одну вкладку.»
- ADR-0029: «Вкладка на каждый открытый файл. Владелец видит в редакторе запущенный nvim, а не файл.»
- ADR-0030: вариант ADR-0028 с причиной «Владелец признал её неудобной», в цитате владельца слова о неудобстве нет.
- ADR-0033: «Оставить панель Blame. Владелец имел в виду другое.»

Отдельно в ADR-0030: шесть вариантов центра вкладки названы одной строкой «Отвергнуты владельцем» без причины. Первый из них, агенты в «Сессиях», по словам совпадает с принятым («Агенты рабочей области перечислены в «Сессиях» навигатора»).

Нужно либо записать настоящую причину отказа, либо убрать варианты, которые никто не рассматривал как альтернативу.
