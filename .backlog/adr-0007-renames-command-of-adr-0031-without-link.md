# ADR-0007 меняет имя команды из ADR-0031 без строки связи

ADR-0007, «Уточнено в P1.4 (планирование)»: «`panel.move-part` из ADR-0031 это то же действие: дефис остаётся написанием CLI (`panel move-part`), а команда называется `panel.move_part`».
В таблице «Действия» ADR-0031 столбец «Команда» по-прежнему даёт `panel.move-part`.
Строки связи нет ни в одной из двух шапок.

Нужно записать уточнение с обеих сторон.
