# Tab после Esc в поле панели начинает с кнопок окна, а не с панели

После `Esc` в поле «Демо: поле» первый ответчик — окно, ни один узел `ui.inspect` его не держит.
`Tab` из этого места идёт по цепочке ключевых видов окна с начала: кнопки зон, кнопка оформления, полосы вкладок левой зоны и центра с их кнопками, и только одиннадцатым нажатием доходит до поля панели с фокусом.
Наблюдение — пункт `field-input` сценария `scripts/e2e/keyboard.sh` (срез 8 задачи 10 плана `navigation-keymap`), цепочка записана в `field-input/tab-chain.txt` прогона.

Маршрутизатор `Tab` в `Navigation` не глотает, действие `mode.input` (`i`) возвращает ввод в поле одной клавишей, поэтому клавиатурный путь есть.
Вопрос к решению: должен ли `Tab` в `Navigation` начинать с панели с фокусом, то есть оставлять первым ответчиком тело панели, а не окно.

Условие наблюдения: системная настройка «Навигация с клавиатуры» (`defaults read -g AppleKeyboardUIMode`) на машине прогона не задана (ключа нет, значение системы по умолчанию).
Обход кнопок клавишей `Tab` может зависеть от неё: число нажатий до поля описывает эту машину, сценарий от него не зависит.
