# В ADR-0037 под одним статусом два решения с разной судьбой

Шапка: «Статус: Proposed».
Правило для планов уже действует: пояснение называет его решением владельца, запись говорит «Дальше правило действует для каждого плана», `docs/roadmap.md` требует раздел «Сверка с прототипом» у каждого плана, шапки ADR-0036 и ADR-0008 несут «Изменено ADR-0037».
Подтверждения ждёт только инструмент сверки.
По одному статусу нельзя понять, действует ли правило.

Нужно разделить решения на две записи или принять правило отдельно. Решает владелец.
