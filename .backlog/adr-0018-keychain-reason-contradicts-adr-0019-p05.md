# Основание хранить токены в Keychain расходится с выводом P0.5

Таблица ADR-0018: «Токены GitHub и GitLab | macOS Keychain | Подпись приложения постоянна (ADR-0019)».
ADR-0019, «Уточнено в P0.5»: постоянная подпись «для самоподписанного кода доступ к Keychain при обновлении не сохраняет», решение о хранении секретов передано новому ADR.
В ADR-0018 вывод не отражён, строка таблицы стоит как действующая.

Нужно записать в ADR-0018 оговорку и ссылку на будущий ADR о секретах.
