# Заголовки кадров и описание crate называют прежнюю версию протокола

`PROTOCOL` в `crates/shellio-control/src/wire.rs:23` равен 3, а тексты рядом отстали:

- `crates/shellio-control/src/wire.rs:1` — «Кадры протокола v2 управляющего сокета»;
- `crates/shellio-control/tests/wire.rs:1` и `:5` — «Эталоны JSON протокола v1», «после публикации v1 формат меняется только новыми вариантами». Вторую фразу отменил раздел «Уточнено в P1.5 (планирование)» ADR-0007: смена снимка поднимает версию протокола;
- `crates/shellio-control/Cargo.toml:3` — описание «протокол v1 управляющего сокета».

Найдено при задаче 6 плана P1.5 (кадры и `shellioctl`). Поведение не затронуто: версию сверяет `hello` по константе. Правка — только тексты, без номера версии в них или со ссылкой на `PROTOCOL`, чтобы не отставать при следующей смене.
