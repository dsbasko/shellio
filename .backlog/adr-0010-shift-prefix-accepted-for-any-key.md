# ADR-0010: «`Shift-` принимается только у именованных клавиш» расходится с разбором

Раздел «Уточнено в P1.6», пункт «Файл»: «Запись `Shift-` принимается только у именованных клавиш, `Shift-h` пишется `H`».
`Chord::parse` (`crates/shellio-keymap/src/chord.rs`) снимает `Shift-` перед любой клавишей, тест утверждает `chord("Shift-h") == chord("H")` и `chord("Shift-;").to_string() == ":"`.
Строка `"Shift-h"` в `keymap.toml` принимается как `H`, а не отключается диагностикой `bad_chord`.
План сформулировал правило верно: «пишется» — о нормализованной записи, ADR заменил это на «принимается».

Нужно написать: «`Shift-` в нормализованной записи стоит только у именованных клавиш, `Shift-h` при разборе равен `H`».
