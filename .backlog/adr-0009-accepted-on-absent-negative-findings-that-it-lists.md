# Статус ADR-0009 держится на отсутствии отрицательных выводов, которые запись перечисляет

«Уточнено в P1.4»: «Отрицательных выводов по модели нет, поэтому статус: `Accepted` по правилу плана».
Тот же раздел ведёт список «Отрицательные выводы и передачи», а раздел P1.5 называет один его пункт прямо: «Так закрыт отрицательный вывод P1.4», и закрывает новой операцией модели.
Почему эти выводы не относятся к модели, не сказано.

Нужно записать границу: какие выводы считаются выводами по модели.
