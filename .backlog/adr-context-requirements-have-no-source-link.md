# Требования в «Контексте» пяти записей стоят без ссылки на источник

Утверждения без названного источника:

- ADR-0004: «Главная ценность приложения это долгие терминальные и агентские сессии». В таблице требований `docs/requirements.md` такой строки нет, ниже таблицы есть «Сессии переживают закрытие окна, падение GUI и обновление».
- ADR-0007: «Терминал и всё приложение должны полностью управляться внешними вызовами». Требование есть в `docs/requirements.md` («Полное управление терминалом через CLI»).
- ADR-0008: «Всё, что открывается в рабочей области, должно быть плагином». В `docs/requirements.md` это «Все возможности — плагины».
- ADR-0009: «Рабочая область состоит из четырёх зон в духе JetBrains Fleet». В `docs/requirements.md` это «Четыре зоны, адаптация плагинов, запись в AGENTS.md».
- ADR-0012: «В рабочей области запускаются Claude Code, Codex и другие CLI-агенты, с флагами по умолчанию из настроек». В `docs/requirements.md` это «Запуск агента с флагами из настроек».

Нужно сослаться на строку требований в четырёх записях и назвать источник мотива ADR-0004.
