# В `plugins.sh` нет нажатия мышью в тело панели: исправление `hitTest:` контейнера без постоянной проверки

Контейнер панели сообщает владельцу о нажатии из `hitTest:` только когда адресат `LeftMouseDown` лежит внутри него (`crates/shellio-appkit/src/panel_stub.rs`, `PanelStubView::receives`, исправление задачи 13 плана P1.5). До исправления нажатие сообщалось и тогда, когда событие доставалось другому виду, и это ломало перетаскивание в `layout.sh` (`move-drag`, `move-drag-body`, `resize-drag`).

Обратную сторону — щелчок во вложенный компонент тела плагина при фокусе на другой панели переводит фокус на эту панель — ни один пункт `scripts/e2e/plugins.sh` не проверяет: сценарий в тело мышью не нажимает (в файле нет `CGEvent`), модульного теста у `hitTest:` нет, потому что тесты `make check` не запускают `NSApplication`.

Наблюдалось один раз 2026-11-24 прогоном вне зачёта: копия сценария `target/task13/plugins-click.sh`, три случая `pass` (строка демо-списка, карточка терминала, поле «Демо: поле») — `target/e2e/plugins/20261124-190004-7607/body-click/verdict.txt`. Каталог `target/` в git не хранится.

Правка — пункт матрицы `plugins.sh` с CGEvent-нажатием в середину узла `ui.inspect` и чтением фокуса по `query.layout` (функции `cg_point`, `click_cg`, `node_point`, `click_case` есть в копии), с записью в матрицу приёмки ADR-0021.
