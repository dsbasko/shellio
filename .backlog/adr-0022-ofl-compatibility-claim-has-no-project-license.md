# ADR-0022 говорит о совместимости OFL с лицензией проекта, которой в репозитории нет

ADR-0022: «С лицензией проекта это совместимо».
Лицензия проекта в записи не названа, в корне нет файла `LICENSE`, в корневом `Cargo.toml` нет поля `license`.
Проверить утверждение нечем.

Нужно назвать лицензию проекта или снять утверждение. Решает владелец.
