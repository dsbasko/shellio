# Экран с другим масштабом получает в ADR-0021 два названия ошибки

Раздел о сценарии сверки: «Окно на экране с другим масштабом: ошибка исполнения «условие пункта»».
Ниже в том же разделе: «Непройденное предусловие (экран, масштаб, оконный менеджер): ошибка исполнения «предусловие: …»».
В этой записи это разные классы: «предусловие: …» выходит до первого пункта, «условие пункта» относится к отдельному пункту.

Нужно выбрать одно название для случая.
