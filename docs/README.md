- [Отчёты проб фазы 0](probes/) — отчёт `<id>-<slug>.md` и выбранные данные в `data/` ([ADR-0034](adr/0034-probe-code.md)). Записаны [P0.2 probe-appkit-shell](probes/p0.2-appkit-shell.md), [P0.3 probe-ghostty-surface](probes/p0.3-ghostty-surface.md), [P0.4 probe-session-survival](probes/p0.4-session-survival.md), [P0.5 probe-update-lifecycle](probes/p0.5-update-lifecycle.md), [P0.6 probe-diff-view](probes/p0.6-diff-view.md), [P0.7 probe-review-api](probes/p0.7-review-api.md) и [P0.8 probe-resource-accounting](probes/p0.8-resource-accounting.md), выбор хоста сессии по P0.4 — в [ADR-0005](adr/0005-session-backend.md). Итог P0.5 по контракту [ADR-0019](adr/0019-distribution-and-updates.md) — «не подтверждено: F/next-read»: обязательные клетки и снятие карантина через brew прошли, обновлённая версия молча не читает секрет Keychain прежней, TCC не наблюдалось (`not_run` без выдачи владельца). Итог P0.6 по [ADR-0002](adr/0002-ui-stack-appkit.md) — отрицательный вывод «`DiffView` на `objc2` не укладывается в бюджеты»: открытие diff в глубине файла и память превышены у обоих вариантов отрисовки в общей фазе подсветки tree-sitter, кадры не подтверждены, вариант для P3.2 по правилу не выбран, вопрос о Swift-оболочке передан владельцу к следующему планированию. Итог P0.7 — матрица возможностей и раздел «Уточнено в P0.7» [ADR-0015](adr/0015-forge-review.md): журнал, якоря и сверка подтверждены на `forge-fake` (все 18 строк матрицы `pass`) и на GitLab CE 19.6.1 (11 из 12 клеток `pass`), сбой посреди отправки журнал переживает без повтора записи. Отрицательный вывод один: CE записывает `draft_note` с позицией прежнего head под текущие `diff_refs`, поэтому путь «остаться на ревизии» для черновиков GitLab этим API не выполняется. Создающие операции и публикация `draft_note` с потерянным ответом остаются `unknown` до выбора пользователя. github.com, gitlab.com и GitHub Enterprise Server не наблюдались (`not_run`) и переданы P4.1. Итог P0.8 по [ADR-0011](adr/0011-resource-accounting.md) — критерий «подтверждённые формулы и базовые бюджеты» выполнен частично: формула памяти, атрибуция, правило неполноты и учёт арен подтверждены, а перевод единиц CPU, формула CPU%, учёт исполняемых участков на настоящих часах и стоимость сэмплера получили `not_run` «шумно», потому что на машине исполнения не было тихого окна проверки фона; замер стоимости и базовые бюджеты переданы P2.4. P0.3 закрыта приёмочным проходом исполнителя ([ADR-0036](adr/0036-autonomous-execution.md)): неустранимой проблемы composition нет, ADR-0003 не пересматривается

- [Интерактивный прототип](../prototype/index.html) — эталон поведения и вида панелей, открывается в браузере. Это HTML и JavaScript, а не код продукта. Вид продукта сверяется с ним по правилу [ADR-0037](adr/0037-prototype-conformance.md), инструмент сверки создал план `prototype-conformance`: план выполнен ([plans/completed/20261125-prototype-conformance.md](plans/completed/20261125-prototype-conformance.md)). В ADR-0023 и ADR-0024 он упомянут по прежнему адресу `~/Box/shellio/prototype`.
