# ADR-0012: Агенты как управляемые TUI-процессы

- Статус: Proposed
- Дата: 2026-11-09
- Заменено [ADR-0028](0028-agents-tab-and-threads.md): одна панель на каждого агента.
- Дополнено [ADR-0028](0028-agents-tab-and-threads.md): список состояний.
- Изменено [ADR-0030](0030-agent-panel-per-agent.md): панель на каждого агента возвращена.

## Контекст

В рабочей области запускаются Claude Code, Codex и другие CLI-агенты, с флагами по умолчанию из настроек.

## Решение

Агентская панель это терминальная панель с профилем запуска и адаптером.
Собственный чат-интерфейс не строится.

Профиль:

```toml
[agents.claude]
command = "claude"
args = ["--model", "opus"]

[agents.codex]
command = "codex"
args = []
```

Настройки на уровне проекта переопределяют глобальные.

Адаптер агента объявляет возможности: установка хуков, источник статуса, способ доставки сообщений, поддержка resume, принудительный режим только для чтения, минимальная и проверенная версии.

Состояния агента: `starting`, `idle`, `running`, `waiting_approval`, `error`, `exited`.
Источник: хуки агента, вызывающие `shellioctl agent status`.
Установщик хуков идемпотентен, использует маркеры, не трогает чужие записи и умеет удалять свои.

Агент, запущенный вручную в обычном терминале, регистрируется тем же хуком.
Без регистрации панель остаётся обычным терминалом.

Статусы видны во вкладке, навигаторе и статус-баре.
Панель, ждущая подтверждения, заметна и доступна в одно действие.

## Отвергнутые варианты

- Чат на Agent SDK с сайдкаром: отдельный рендер ленты, ограничения вокруг входа по подписке и дополнительная память.
- Разбор экрана как основной источник статуса: хрупко, допускается только для ситуаций, которые хуки не покрывают.

## Последствия

Опыт агента остаётся родным.
Версии хуков агентов меняются независимо, поэтому нужна матрица совместимости.

## Основания

`agterm/.claude/rules/control-api.md` (Installation and agent integrations), `detached/PLAN-EXTENSIBLE.md` (ответы спайка о размере CLI и условиях входа).

## Условие пересмотра

Появление стабильного протокола агентов, дающего существенно больше, чем TUI.
