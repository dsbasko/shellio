# ADR-0009: Раскладка, четыре зоны и адаптация панелей

- Статус: Proposed
- Дата: 2026-11-09

## Контекст

Рабочая область состоит из четырёх зон в духе JetBrains Fleet: левой, правой, центральной и нижней. Панели могут жить в любой допустимой зоне и обязаны быть там удобны.

## Решение

Раскладка — чистая модель `shellio-layout` без AppKit. Она описывает зоны, вкладки, деревья сплитов, размеры, скрытие и `zoom`, сериализуется и тестируется отдельно. AppKit-адаптер сводит дерево к иерархии `NSView`.

Сопоставление с AppKit:

- Левая зона — `NSSplitViewItem` сайдбара, правая — инспектора, поэтому поведение системное. Поверхности непрозрачны ([ADR-0023](0023-opaque-window-and-shell.md)).
- Центральная и нижняя зоны — вертикальный сплит внутри основной области, нижняя занимает ширину центра.
- Центр поддерживает вкладки и произвольные сплиты. Боковые и нижняя зоны — вкладки и один уровень сплита.

Адаптация идёт по двум осям:

```rust
pub struct Geometry { pub zone: Zone, pub size: SizeClass, pub width: f64, pub height: f64 }
pub enum SizeClass { Narrow, Regular, Wide, ShortBar }
```

- Метод `adapt` разбирает `Zone` исчерпывающим `match` без `_`, чтобы новая зона не прошла незамеченной.
- Панель не копируется на четыре реализации. Это одна модель и разные представления.
- Ниже `min_size` хост показывает компактную заглушку с действием «Развернуть». Нечитаемых миниатюр нет.
- Все действия панели доступны с клавиатуры в любой зоне. В компактном виде путь к ним идёт через раскрытие вглубь или `zoom`.

Правило закреплено в `AGENTS.md` и проверяется контрактным тестом: каждый плагин проходит фикстуры всех зон и размеров.

Перенос панели мышью и клавишами сохраняет `PanelId`, `SessionId` и фокус. Сброс раскладки не останавливает процессы.

## Отвергнутые варианты

- Dock-компонент gpui-kit: отвергнут вместе с GPUI. В испытанной в detached конфигурации были ограничения: полоска закрытой зоны и запрет на перенос последней вкладки.
- Вложенные `NSSplitView` как единственная модель: состояние окажется в AppKit и станет нетестируемым.

## Последствия

Адаптер раскладки — один из самых сложных компонентов фазы 1. `NSView` терминала при обычном переключении вкладок остаётся смонтированным, повторная установка родителя идёт только при явном переносе.

## Основания

`detached/PLAN-EXTENSIBLE.md` (шаг 3, цена `DockArea`), `agterm/ARCHITECTURE.md` (Surface ownership: повторное размещение сбрасывает Metal drawable).

## Условие пересмотра

P0.3 покажет, что перенос Metal-поверхности между зонами вызывает неприемлемые артефакты.
