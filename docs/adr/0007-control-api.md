# ADR-0007: Управляющий API и CLI

- Статус: Proposed
- Дата: 2026-11-09

## Контекст

Терминал и всё приложение должны полностью управляться внешними вызовами, чтобы фоновые задачи и агенты могли работать с ними.

## Решение

Единый слой команд: действие из меню, по клавише, из палитры и из CLI вызывает один и тот же типизированный `Command` с одним обработчиком. Новое действие считается законченным, когда у него есть команда, CLI, чтение результата и тесты.

Транспорт: Unix-сокет с правами `0600` и проверкой UID собеседника, JSON построчно, лимит 1 МиБ на запрос. Первая команда клиента — `hello` с версией протокола. Ошибки структурированы и имеют стабильные коды. Путь сокета короче 104 байт.

CLI `shellioctl` (названия уточняются в P1.2):

- `tree`, `status`, `version`
- `workspace|project|workbench list|new|open|focus|rename|close`
- `panel list|open|focus|move|hide|close-view|remove`
- `pane text|type|paste|run|search|resize|copy`
- `session list|start|stop|attach`
- `agent list|start|status|ask|task|cancel`
- `msg send|read|ack`
- `events --since <cursor>`, `metrics`, `keymap reload`, `config reload`

Цель всегда задаётся явно (`--target`) либо берётся из окружения `SHELLIO_SESSION_ID`, `SHELLIO_PANEL_ID`, `SHELLIO_SOCKET`. Команда с явной целью не зависит от текущего фокуса.

Вывод — JSON с `--json`, иначе человекочитаемый. Каждая команда, меняющая состояние, видна в `tree` или в собственном чтении.

События: журнал с монотонным курсором. Клиент, потерявший поток, получает снимок и ревизию. Команды, которым нужен UI при закрытом окне, возвращают явный результат `no-ui`.

Сокет защищает от других пользователей, но не изолирует процессы одного пользователя.

Потоковая трансляция вывода терминала в протокол не входит. Чтение экрана — разовая команда.

## Отвергнутые варианты

- Отдельный API для CLI: логика разойдётся с интерфейсом.
- gRPC и HTTP: лишний вес для локального канала.

## Последствия

Плагин, добавляющий действие, обязан объявить его как команду. Ручное действие без команды — дефект.
