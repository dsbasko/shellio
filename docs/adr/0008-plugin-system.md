# ADR-0008: Система плагинов

- Статус: Proposed
- Дата: 2026-11-09

## Контекст

Всё, что открывается в рабочей области, должно быть плагином, чтобы систему можно было расширять без глобальных переделок. Стабильного ABI у Rust нет.

## Решение

Плагин — Rust-crate в `plugins/<id>`, зарегистрированный на этапе компиляции и реализующий контракт из `shellio-plugin-api`. Встроенные возможности используют тот же контракт, что и любой будущий плагин.

Манифест:

```rust
pub struct Manifest {
    pub id: &'static str,              // "blame"
    pub title: &'static str,
    pub icon: Icon,
    pub placements: ZoneSet,           // допустимые зоны
    pub default_zone: Zone,
    pub cardinality: Cardinality,
    pub min_size: MinSize,
    pub commands: &'static [CommandSpec],
    pub keymap: &'static [KeyDefault],
    pub state_version: u32,
}

pub enum Cardinality { Multi, PerWorkbench, PerProject, PerWorkspace, PerApp }
```

Жизненный цикл панели: `create`, `adapt(Geometry)`, `activate`, `deactivate`, `snapshot`, `restore`, `close_view`, `stop_work`, `dispose`. `close_view` отменяет только работу, привязанную к виду. Работа сессии и начатая публикация ревью не отменяются.

Плагин состоит из двух половин, и регистрация содержит обе фабрики:

- UI-free модель: состояние и команды, работает в акторе, тестируется без окна.
- Фабрика вида: выполняется только на главном потоке, собирает `NSView` из безопасных компонентов `shellio-appkit` (терминальные панели также из `shellio-ghostty`), имеет `!Send` время жизни и получает неизменяемые снимки.

Правила границы:

- Модель зависит от `shellio-plugin-api` и сервисных crate, вид ещё и от безопасных UI-crate. Зависимость от другого плагина запрещена.
- Сырые вызовы `objc2` и `unsafe` в плагинах запрещены.
- Встроенные плагины объявляют `placements` на все четыре зоны. Ограниченный набор допускается только для будущих внешних типов.
- Взаимодействие плагинов только через типизированные команды шины: `blame.open { path, line }`.
- Конкретные плагины знает только composition root `apps/shellio`.
- Окно, раскладка, фокус, сессии, хранилище и телеметрия принадлежат хосту и плагинами не являются.
- Запись в дерево раскладки только через команды хоста.
- Работа в фоне отменяема и ограничена. Скрытая панель не опрашивает сеть бесконечно.

Кардинальность проверяется атомарно в слое команд: `open-or-focus` одинаково работает из UI и CLI. Для blame действует `PerWorkbench`: повторное открытие переводит существующую панель на новый файл и строку, сохраняя историю «назад». `PerWorkspace` даёт одну панель на воркспейс со своими фильтрами, так работает каталог проектов ([ADR-0025](0025-workspaces-and-project-catalog.md)).

Отсутствующий при восстановлении плагин оставляет панель-заглушку с сохранённым состоянием.

Плагины первой поставки: `navigator`, `terminal`, `agent`, `agents-hub`, `editor`, `changes`, `blame`, `review`, `pipelines`, `resources`.

Внешние плагины не входят в первую версию. Если они понадобятся, это исполняемый процесс с протоколом поверх управляющего API, декларативными панелями и терминальными вкладками. План P5.7 создаётся по решению владельца.

## Отвергнутые варианты

- `dylib` с `abi_stable`: хрупкая граница ради отсутствующих внешних авторов.
- WASM: песочница без потребности, а нативный `NSView` через неё не пройдёт.
- Каждая панель в отдельном процессе: цена памяти и IPC на каждый список и diff.

## Последствия

Добавление возможности — новый crate и одна строка регистрации. Сторонний плагин без пересборки в первой версии невозможен.

## Основания

[Rust ABI не стабилен](https://doc.rust-lang.org/reference/abi.html). `detached/PLAN-EXTENSIBLE.md` (решение без `crates/sdk`, манифест как единственный публичный контракт), `detached/crates/app/src/dock/mod.rs` (закрытый `enum Kind` мешает расширению).

## Условие пересмотра

Появление реальной потребности в плагине, который нельзя собрать вместе с приложением.
