# Architecture Decision Records

Каждое значимое решение проекта записано здесь отдельным файлом. Новое решение получает следующий номер. Принятое решение не переписывается: если оно меняется, создаётся новый ADR, а старый получает статус `Superseded`.

Статусы:

- `Proposed` — выбранный вариант, который ещё должна подтвердить проба или реализация.
- `Accepted` — решение принято и действует.
- `Superseded by ADR-NNNN` — заменено другим решением.

Разделы файла: контекст, решение, отвергнутые варианты, последствия, основания, условие пересмотра.
