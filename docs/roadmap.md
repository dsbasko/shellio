# Дорожная карта

Проект разбит на шесть фаз и 42 плана. Один ralphex-план — один обозримый результат с проверкой и обновлением связанных ADR. Детальные планы создаются отдельными запросами и лежат в `docs/plans/YYYYMMDD-<slug>.md`.

Правила:

- План заканчивается зелёным `make check`.
- Исполнение автономное, владелец участвует только в планировании (ADR-0036). План записывает правило для каждого предвидимого выбора.
- План с UI-результатом содержит приёмочный проход исполнителя: пункты с критерием `pass` и сырым артефактом. Ненаблюдаемое автоматикой получает `not_run` с причиной.
- Каждое новое действие получает команду, CLI, чтение результата и тесты (ADR-0007).
- Каждый плагин проходит контракт зон (ADR-0009).
- Колонка «Зависит от» задаёт полный граф зависимостей. Планы без связи можно выполнять параллельно.
- Завершённый план переносится в `docs/plans/completed/`, а его строка здесь получает ✅ вместо ⬜ в колонке «Готов». Оба шага входят в последний пункт плана и коммитятся вместе. Шаг из нескольких планов отмечается последним из них.
- Обновление ревизии libghostty — отдельный внеочередной план `ghostty-bump-<rev>` по процедуре ADR-0003.

Порядок намеренный: сначала проверяются рискованные решения, затем появляется терминал и агенты для ежедневной работы, и только потом функциональность git и ревью.
